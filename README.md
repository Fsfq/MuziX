# MuziX

MuziX — современный локальный аудиоплеер для Android на Jetpack Compose с кастомным DSP-движком (ViPER-FX / FsFqX), синхронизированным караоке-текстом и рекомендательным потоком "Волна".

## Возможности

- **Интерфейс Material 3 You:** динамические цвета системы, адаптивные анимации, Dynamic Island оверлей и фоновые градиенты по цветам обложки трека.
- **DSP-движок FsFqX (на базе формул ViPER-FX):**
  - 10-полосный параметрический эквалайзер
  - Суббас (Natural Bass / Pure Bass) с настраиваемым срезом
  - Гармонический экситер высокой четкости
  - Ламповое утепление (AnalogX)
  - Стерео-расширитель 3D и компрессор/лимитер пиков
  - Пресеты реверберации
- **Синхронизированный текст:** парсинг LRC, автоматический поиск через LRCLIB, караоке-скролл с подсветкой текущей строки.
- **Рекомендательная лента "Волна":** локальный подбор похожих треков и артистов по настроению и жанрам через встроенный Python-модуль (`wave_engine`).
- **Встроенный загрузчик:** сохранение аудио и обложек, редактирование ID3-тегов (Chaquopy + mutagen / yt-dlp).
- **Фоновое воспроизведение:** интеграция с Media3 (`MediaSessionService`), управление через шторку, экран блокировки и системные плитки Quick Settings.

## Стек технологий

- **Языки:** Kotlin 2.0+, Python 3.8 (Chaquopy)
- **UI:** Jetpack Compose, Material Design 3 Expressive
- **Аудио:** AndroidX Media3 (ExoPlayer), кастомный `AudioProcessor`
- **База данных:** Room SQLite
- **Изображения:** Coil 3
- **Сборка:** Gradle (Kotlin DSL), R8 Full Mode

## Сборка из исходников

Требования:
- Android Studio Ladybug / Meerkat или JDK 17+
- Android SDK (compileSdk 37, minSdk 24)

Сборка релизного APK:
```bash
./gradlew assembleArm64Release
```

Сборка 32-битной версии (для старых устройств):
```bash
./gradlew assembleArm32Release
```

Собранные APK будут находиться в каталоге:
`app/build/outputs/apk/<flavor>/release/`
